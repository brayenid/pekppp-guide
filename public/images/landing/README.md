# Slot Gambar Landing Page PEKPPP Kutai Barat

Unggah berkas gambar ke dalam folder ini (`public/images/landing/`). Halaman utama (`src/app/page.tsx`) akan otomatis mendeteksi dan menampilkan gambar begitu berkas disimpan (mendukung format `.jpg`, `.jpeg`, `.png`, `.webp`, atau `.avif`):

1. **`hero-kubar.jpg`** (Rasio `16:10`, rekomendasi `1200×750 px`)
   - Ditampilkan pada kolom kanan Hero utama.
   - Subjek: Foto Gedung Kantor Bupati / Kompleks Perkantoran Pemkab Kutai Barat atau aktivitas loket pelayanan publik.

2. **`verifikasi-lapangan.jpg`** (Rasio `16:9`, rekomendasi `960×540 px`)
   - Ditampilkan pada seksi *Mekanisme Evaluasi Terpadu*.
   - Subjek: Dokumentasi kegiatan verifikasi & uji petik lapangan (F-02) atau pendampingan evaluasi perangkat daerah oleh Bagian Organisasi.
